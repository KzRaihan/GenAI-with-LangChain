# GenAI-with-LangChain
A hands-on repository for learning and building Generative AI applications with LangChain, covering LLMs, prompt engineering, RAG, embeddings, vector databases, agents, and production-ready AI workflows.

### 1️⃣ Clone the Repository

```
    git clone https://github.com/KzRaihan/GenAI-with-LangChain.git

```

### 2️⃣ Create a Virtual Environment

```
    conda create -n GenAI python=3.11
```

### 3️⃣ Activate the Environment

```
    conda activate GenAI
```

### 4️⃣ Install Dependencies

```
pip install -r requirements.txt
```
